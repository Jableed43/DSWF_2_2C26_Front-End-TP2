Aplicación en React hecha en equipo para la materia **Desarrollo de Sistemas Web Front End** (comisión 2C26, 2026). Continúa el sitio del TP1: presenta al equipo, un perfil por integrante, datos propios con búsqueda y filtro, una API pública y la bitácora del proceso, todo dentro de una sola aplicación con sidebar.

## Descripción

La aplicación se organiza desde una sidebar compartida que muestra la identidad del equipo, enlaza a todas las secciones e indica cuál está activa. Contiene:

- **Portada:** presenta al equipo y da acceso a los perfiles.
- **Perfiles:** uno por integrante, construidos con un mismo componente que recibe sus datos por props.
- **Datos locales:** listado de al menos 20 registros desde un JSON, con búsqueda por texto y filtro.
- **API pública:** resultados de una API con estados de carga y error.
- **Árbol de renderizado:** jerarquía de componentes de la aplicación.
- **Bitácora:** registros del proceso de trabajo, que continúan los del TP1.

## Cómo correrlo en local

```bash
npm install
npm run dev
```

Después abrir la dirección que indica la terminal (por defecto `http://localhost:5173`).

Para generar la versión de producción:

```bash
npm run build
```
